Introduction

This repository contains the code for a disease prediction web application. The app utilizes machine learning models to predict the likelihood of various diseases based on user inputs. The primary aim is to provide an accessible and intuitive platform for early disease detection, which can be instrumental in preventive healthcare.



Features

User-friendly interface for inputting health data

Real-time disease prediction based on user inputs

Visual representation of prediction results




Technologies Used

Python: Backend logic and machine learning models

Streamlit: Web framework for creating the web app

Scikit-learn: Machine learning library for training models

Pandas: Data manipulation and analysis



Project Structure

diabetes_model.sav: Serialized machine learning model for diabetes prediction.

heart_disease_model.sav: Serialized machine learning model for heart disease prediction.

parkinsons_model.sav: Serialized machine learning model for Parkinson's disease prediction.

mdps_public.py: Main script for running the Streamlit web app.

requirements.txt: List of Python packages required for the project.
